# 0001 - 纯前端架构，无后端无数据库

用户明确选择纯前端架构：所有平台 API 凭据与快照数据仅存于用户浏览器（localStorage），不设后端、不用数据库、不做登录。Vercel 上仅部署静态站点。

**原因**：凭据不上传任何服务器，规避「第三方保管密钥」的安全顾虑（用户原话：否则别人会有安全防范）；同时省去数据库与运维成本。可行性已验证：OKX web3 API 与 Binance REST API 均允许浏览器跨域（OKX 预检放行自定义 `OK-ACCESS-*` 头并回显 Origin；Binance 全端点 `access-control-allow-origin: *`）。

**代价**：每日 UTC+8 24:00 的自动快照仅在页面打开时执行；浏览器清空数据即丢失全部历史，需导出/导入 JSON 备份兜底。
