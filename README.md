# BalanX — CEX/DEX Balance Monitor

Cross-exchange balance monitor: real-time USD value of every wallet across **OKX DEX** (OnchainOS) and **Binance**, in one dashboard. Pure frontend — **no backend, no database**. All API credentials and snapshot history live in your browser's localStorage.

> ⚠️ **Current state: design demo.** All data is mocked in the browser. Real API wiring (OKX signed requests, Binance HMAC endpoints) comes next, pending your sign-off on the design.

## Run

```bash
npm install
npm run dev
# → http://localhost:3000
```

## Planned features (this demo covers the UI shell)

- Total asset overview with portfolio history chart (30-day snapshots)
- Add / delete accounts (OKX DEX: name + API Key + Secret Key + Passphrase + wallets + chains ETH/BSC; Binance: name + API Key + Secret Key)
- DEX token-level detail · Binance per-type subtotals (Spot / Funding / Margin / Earn / Futures incl. unrealized PnL)
- Manual refresh + daily auto-refresh at UTC+8 24:00 (fires only while the page is open)
- Snapshots: daily auto + manual, backed up via export/import JSON
- EN / 中文 i18n (English default)

## Verified API facts (for the wiring phase)

- OKX OnchainOS Balance API allows browser CORS (preflight passes custom `OK-ACCESS-*` headers); auth = apiKey + secretKey + passphrase
- Binance `api.binance.com` / `fapi` / `dapi` all send `access-control-allow-origin: *`; 8 signed endpoints cover Spot / Funding / Margin (cross+isolated, net) / Simple Earn / Futures USDT-M + COIN-M
